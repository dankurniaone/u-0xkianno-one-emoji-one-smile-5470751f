# One Emoji, One Smile

One emoji, chosen to make a stranger smile, written for the [One Emoji, One Smile](https://make.fun/competitions/u-0xkianno-one-emoji-one-smile-5470751f) bounty on [make.fun](https://make.fun).

## The emoji

> 🤗

A hugging face: open arms and a smile. Warm at first glance, the same read for any age or background, clearly a chosen gesture rather than the default smiley, and welcoming without intimacy, sarcasm or flirtation — exactly what the judge's brief rewards.

## Run it

```sh
node main.ts
```

`main.ts` writes the single emoji to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`), checking the gate first: UTF-8 text of 1–8 characters, not only white space.
